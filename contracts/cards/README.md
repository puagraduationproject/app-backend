# Cards

The AI answers only with these cards, and the windows use the same ones. An
unknown card shows its plain text. One page per card.

- [`order`](order.md): An order with its lines, total, stage and ready time; buttons to confirm, edit or cancel
- [`item`](item.md): An item with sizes, options, price and photo; cost and margin when the role allows
- [`stock`](stock.md): Stock levels, what runs out and when
- [`customer`](customer.md): A customer: history, usual order, points, notes, open cases
- [`cash`](cash.md): A shift's expected and counted cash, and the gap
- [`sales`](sales.md): Sales for a period, by item, hour, staff or channel
- [`approval`](approval.md): One action waiting: Approve, Approve and always allow this, Decline, Never let the AI do this
- [`plan`](plan.md): A multi-step plan: the reads done, the writes to do, one approval for all
- [`question`](question.md): One question from the AI with a few choices to tap, and a box for another answer
- [`post`](post.md): A post preview: image, captions, channels and time
