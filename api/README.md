# API

One tool API, four doors. There is no second, hidden way in.

- [`app`](app/README.md): Logged-in members, by session
- [`ai`](ai/README.md): The AI layer: a service token plus who it acts for
- [`public`](public/README.md): Shop pages, the chat widget, channel webhooks
- [`outside`](outside/README.md): Outside websites with an API key per business (term 2)
