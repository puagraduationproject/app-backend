- [`erp`](erp/README.md): ERP, 54 tools
- [`crm`](crm/README.md): CRM, 31 tools
- [`channels`](channels/README.md): Channels, 12 tools
- [`store`](store/README.md): Store website, 10 tools
- [`studio`](studio/README.md): Studio, 10 tools
- [`marketing`](marketing/README.md): Marketing, 6 tools
- [`team`](team/README.md): Team, 10 tools
- [`reports`](reports/README.md): Reports, 5 tools

The AI layer's tools (`ai.*`) are listed in [contracts/tools](../contracts/tools/README.md); the AI layer lives in `app-ai-agent`.
